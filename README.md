## 🚀 Featured Project

### 📊 Student Performance Analysis & Prediction

A machine learning project that analyzes student performance based on:

* 📚 Study Hours
* 📅 Attendance
* 📝 Previous Marks

The project uses **Python, Pandas, Matplotlib and Scikit-learn** to analyze the data and predict final marks.

**Model Performance:**

* MAE: **0.65**
* R² Score: **0.98**
* Dataset: **20 students**
